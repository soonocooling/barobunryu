# 화면 흐름 (screen-flow)

원본 앱(토스) 캡처를 기준으로 정리한 화면 흐름. 값(금액·이름·가맹점)은 쓰지 않고 **필드와 출처만** 적는다.
`[받아옴]` = 서버에서 온 값, `[저장]` = 사용자가 입력·변경한 값. 원본 캡처는 `docs/원본캡처/_원본/`(커밋 제외)에 있다.

## 1. 소비 요약 (월 단위)
- 월 이동 ◀ ▶ `[받아옴]`, 탭: 전체 / 카드 / 입·출금 / 투자 / 페이·기타
- 이번 달 **지출 합계**, **수입 합계** `[받아옴]`
- 지난달 대비 문구, 주간 달력(요일별 그날 지출 합계) `[받아옴]`
- 소비 분석: 카테고리별 금액 막대 + 상위 3개 + `그 외 N개` `[받아옴]`
- 예상 남는 돈 / 예상 수입(3개월 평균) / 앞으로 나갈 돈 / 고정지출 `[받아옴]`

## 2. 거래 내역 목록
- 날짜 구분(`3일 화요일`), 날짜 옆 `평소보다 많이 씀` 같은 상태 문구 `[받아옴]`
- 거래 한 줄: 가맹점 아이콘, 금액(출금은 `-`), **`내 하나계좌 → 가맹점명`** 형태의 출처→상대 `[받아옴]`
- 사람 간 이체: `내 계좌 이체 | 본인이름 → 은행명` 형태 `[받아옴]`
- 목록에는 **카테고리가 직접 표시되지 않는다.** 카테고리는 1번 화면의 합계와 3번 화면에서만 보인다.
- 검색창(`지출·수입 검색`)

## 3. 거래 상세 → 카테고리 변경
상세 내역
- 가맹점 이름, 금액 `[받아옴]` — 금액 옆 **연필 아이콘**(금액 수정 가능으로 보임, 동작은 미확인)
- **카테고리 설정**: 현재 카테고리 `[받아옴]` → 눌러서 변경 `[저장]`
- **메모**: 자유 입력 `[저장]` (기본 문구 `메모를 남겨보세요`)
- **지출 합계에 포함** 스위치 `[저장]` — 거래를 합계에서 빼는 기능
- 우상단 `숨기기` `[저장]`

카테고리 변경
- 현재 카테고리와 거래 요약(`내 하나계좌 → 상대`) 표시, 안내 문구 `변경할 카테고리를 선택해주세요`
- 선택지 `[받아옴]`: 식비, 카페·간식, 편의점·마트·잡화, 술·유흥, 쇼핑, 취미·여가, 의료·건강·피트니스, 주거·통신, 보험·세금·기타금융, 교통·자동차, 여행·숙박 … (캡처가 아래에서 잘려 있고, 소비 분석에는 `미용`도 나온다 → 최소 12개 이상)
- **"같은 가맹점 모두 변경" 같은 선택은 캡처된 범위에 없다.** 학습 여부는 확인 불가.

## 우리 서비스와 비교
| 원본 | 우리 |
|---|---|
| 결제 후 사용자가 앱에 들어가 **직접** 카테고리를 찾아 바꾼다 | 애매한 거래만 결제 직후 **텔레그램이 먼저 묻는다** |
| 선택지 고정(버튼 목록) | 자유 입력("치킨 4명")도 받는다 |
| 정산 기능 없음(정산은 카카오페이에서) | 엔빵이면 내 몫만 지출로 기록 |
