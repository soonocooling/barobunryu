# 현장 시연 대본 (1분) — 담당 조원영

발표 때 현장에서 직접 시연한다(화면 녹화 없음). 기준은 `docs/collab-plan.md` 10장 데모 시나리오다.
이름은 더미(별칭)를 쓴다. 실제 이름·금액·계좌는 화면에 띄우지 않는다.

## 1분 시간표
| 시간 | 할 일 | 입력 (텔레그램) | 보여줄 결과 | 말할 것 |
|---|---|---|---|---|
| 0~10초 | 문제 한 줄 | — | — | "결제 앱은 내역에서 직접 카테고리를 찾아 바꿔야 하고, 카카오페이 결제는 '그 외'로 묻힙니다. 우리는 애매한 것만 결제 직후 먼저 묻습니다." |
| 10~20초 | 확실한 건 조용히 | `스벅 6500` | 질문 없이 카페·간식으로 분류 | "확실한 건 묻지 않습니다." |
| 20~30초 | 공개 API 분류 + 더치페이 의심 | `46000 교촌치킨` | 카카오 분류로 식비, `[더치페이?]` 질문 | "가맹점은 카카오 로컬 API로 분류하고, 큰 금액은 더치페이인지 묻습니다." |
| 30~40초 | 대충 쓴 답 | 질문에 답장 `4명` | ✅ 식비 · 4명 더치페이 (내 몫 11,500원) | "대충 쓴 답도 알아듣고 내 몫만 지출로 잡습니다." |
| 40~50초 | 이체 용도 | `50000 상대A 이체` → 버튼 `주거·통신` | 질문 → 1탭으로 확정 | "이체는 원본이 용도를 모르지만 우리는 물어봅니다." |
| 50~60초 | 대시보드 | (브라우저) | 이번 달 식비 11,500원 | "46,000원이 아니라 내 몫 11,500원으로 잡힙니다." |

시연에서 뺀 단계(발표 중 말로만, 또는 사전 확인):
- 시나리오 6 `+11500 상대B` × 3 → 정산 자동 매칭. 시간이 남을 때만 보여준다.
- 시나리오 7 5분 대기 → 같은 질문 재발송 없음. **현장에서 기다리지 않는다.** 사전에 한 번 확인해 두고 "5분마다 돌아도 같은 질문은 다시 안 옵니다"로 말한다.

## 단계 사이에 반드시 할 것
각 입력 뒤에 GitHub Actions의 `Run workflow`를 눌러야 봇이 답한다(5분 주기를 기다리면 시연이 안 된다). 순서를 손에 익혀 두고, 입력은 **미리 복사해 둔 메모**에서 붙여 넣는다.

## 사전 준비 체크 (발표 전날과 당일)
- [ ] 데모용 텔레그램 대화방을 비우고 시작 상태로 만든다
- [ ] 데모에 쓸 입력 7줄을 메모장에 미리 적어 둔다
- [ ] 시연 순서대로 1회 리허설해서 `Run workflow` 시간이 얼마나 걸리는지 잰다
- [ ] 리허설에서 만든 거래를 지우거나, 발표용 데이터가 깨끗한지 확인한다(식비가 11,500원이 되려면 리허설 데이터가 남아 있으면 안 된다)
- [ ] 인터넷이 끊길 때를 대비해 폰 핫스팟을 준비한다

## 대시보드 확인 (배포 URL은 권순오가 전달)
URL: `(권순오 전달 후 기입)`

- [ ] 비밀번호를 넣어야 열린다(없으면 로그인 창만 뜬다)
- [ ] 로그인하면 빨간 안내 없이 6칸이 보인다
- [ ] 화면 아래에 "장소 분류 데이터: Kakao Local API"가 있다
- [ ] 데모 후 이번 달 식비가 **11,500원**이다(46,000원이 아니다)
- [ ] 비밀번호는 발표 화면에 보이지 않게 입력한다(화면 공유 중 노출 주의)

## 발표에서 주의할 말
- "토스가 더치페이 대표결제를 전액 지출로 잡는다"는 **캡처로 확인하지 못했다.** 단정하지 않는다.
- 캡처로 뒷받침되는 말: ① 토스는 내역 목록에 카테고리를 보여주지 않고 상세 화면에서 직접 바꿔야 한다 ② 카카오페이 출금은 상위 카테고리 밖(`그 외`)으로 합산된다 ③ 토스에는 정산 기능이 없고 정산은 카카오페이에서 한다.
- 원본 서비스 이름과 로고는 화면과 발표 자료에 쓰지 않는다.

## 문제가 생기면
| 증상 | 대응 |
|---|---|
| 봇이 답하지 않음 | `Run workflow`를 눌렀는지, Actions 탭이 초록인지 본다. 그래도 안 되면 미리 찍어 둔 정지 화면(캡처 이미지)으로 설명한다 |
| 카카오 분류가 비어서 식비로 안 나옴 | 키워드 분류가 받쳐 준다(교촌은 `keywords.json`에 있다). 그대로 진행한다 |
| 대시보드가 빨간 안내를 띄움 | 연결 문제다. 텔레그램 화면만으로 시연을 마치고 대시보드는 사전 캡처로 대신한다 |
