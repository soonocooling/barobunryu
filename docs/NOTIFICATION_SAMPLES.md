# 거래 알림 샘플 준비

현재 `parse.parse_push(raw)`는 스텁이다. `watch.process_inbox()`가 호출하며,
None이면 inbox의 원문과 new 상태를 보존한다. 포맷을 추측해 처리하지 않는다.
사진은 현재 자동으로 다운로드하거나 OCR 처리하지 않는다.

샘플을 받을 때 필요한 정보:

- 알림을 보낸 앱/은행/카드사와 알림 제목
- 줄바꿈·공백·금액·시간 표기를 유지한 전체 알림 텍스트
- 카드 결제, 출금 이체, 입금 이체 각각의 예시
- 각 예시의 기대 결과: 거래 시각, 금액, 입출금 방향, 카드/이체, 상대 이름
- 거래금액과 잔액이 함께 표시되는 예시 및 취소·환불 예시
- 거래 시간이 없을 때 사용할 시각 기준

사진과 함께 복사한 텍스트도 있으면 실제 inbox 입력과 대조할 수 있다.
계좌/카드 번호·개인 이름은 일관된 가명으로 가리되 주변 문구와 배치는 유지한다.
확인된 샘플은 `tests/fixtures/push_samples.json`에 기대 결과와 함께 추가한다.

## 테스트 봇 실행

실제 실행은 이번 작업에서 수행하지 않았다. 실행 준비 시 `.env.local`의
`TEST_TELEGRAM_BOT_TOKEN`, `TEST_TELEGRAM_CHAT_ID`에 별도 테스트 봇 값을 넣는다.
`python watch.py`는 이 두 값이 없으면 네트워크 호출 전에 중단하며,
일반 `TELEGRAM_BOT_TOKEN`으로 대체하지 않는다. 토큰이 실제 테스트 봇의 것인지
자체 판별할 수는 없으므로 운영 봇 값을 넣지 않는다.

한 번 업데이트를 수신하고 상태를 `state.test.json`에 저장한다. 실행하면
Telegram뿐 아니라 설정된 Supabase와 분류 조건에 따라 Kakao에도 요청할 수 있다.
운영 DB를 변경하지 않도록 테스트용 Supabase 설정을 사용한다.

원문 파서, 정산 자동 매칭, 요약 명령은 아직 완성되지 않았다.
